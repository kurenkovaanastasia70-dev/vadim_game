# Подготовка форка

1. Создавайте форк только с веткой `main`, если история рабочих веток исходного репозитория не нужна.
2. Клонируйте форк и установите зафиксированные зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Перед разработкой выполните проверки из README или дождитесь успешного workflow `Baseline`.
4. В настройках форка защитите `main`: запретите force push и удаление, требуйте pull request и успешные проверки `Python 3.11` и `Python 3.12`.
5. Удаляйте слитые рабочие ветки. Новые изменения делайте в короткоживущих ветках от актуального `main`.

GitHub-настройки защиты ветки не хранятся в Git, поэтому их нужно включить отдельно после создания форка.
