# Фича 1. Появление призрака (= FSM main + drain)

## 1.1. Смысл

Призрак **не** получает отдельный «идти к игроку» ивент и **не** завершается касанием.  
Работает обычный алгоритм из `main` (невидим → появляется → патруль/поиск…).  
Когда FSM выходит из `INVISIBLE` на карту — **один раз** снимается рассудок (`SANITY_GHOST_EVENT_DRAIN`).

Событие активности остаётся простым ambient (тост + небольшой drain), без спец-проявления.

## 1.2. Карта файлов

| Файл | Роль |
|---|---|
| `ghost.py` | В момент появления FSM вызвать `appearance_callback` |
| `main_work.py` | `on_ghost_appeared_on_map` → `drain_sanity` |

## 1.3. Порядок

1. Константа `SANITY_GHOST_EVENT_DRAIN`  
2. `GhostManager.appearance_callback`  
3. В ветке INVISIBLE→IDLE уведомить callback  
4. `Game.on_ghost_appeared_on_map`  

## 1.4. Проверка

```text
# ghost.update_state из INVISIBLE → sanity −10, state != invisible
# призрак дальше живёт обычным FSM (не «летит» к игроку отдельным тиком)
```

# Фича 4. Задания сессии и уровни

## 4.1. Решение по дизайну

- **Задания** — сессионные: прогресс и награда идут в **session-$**, список **сбрасывается/подменяется при старте уровня**.  
- **Ачивки** — глобальные на слот сейва: награда в **счёт**, не зависят от уровня.  
- **Конфиг по уровням — да, нужен**: разные выезды просят разное (на 1 уровне «купи фонарик», на 2 — «соль»).  
  Источник: поле `"tasks": [...]` в `levels_index.json` для `level_id`.  
  Если поля нет — `DEFAULT_TASK_CATALOG` из `progression.py`.

Почему не один общий список на всю кампанию: иначе накликивание session-$ через одни и те же тривиальные задания на каждом реплее; и обучение предметам уровня размывается.

## 4.2. Карта файлов

| Файл | Роль |
|---|---|
| `levels_index.json` | опциональный `tasks` на уровень |
| `progression.py` | `resolve_task_catalog`, `new_tasks_for_level`, награда → `player_money` |
| `main_work.py` | `_after_level_ready` подтягивает задания уровня |

## 4.3. Проверка

```text

```

## Ручной прогон

1. Магазин: видны сессия и счёт; моды за счёт.  
2. Дождаться обычного появления призрака (30–90 с первого) — sanity падает, призрак патрулирует.  
3. Радио вне setup — иногда cursed hunt.  
4. Выполнить задание уровня — растёт сессия.  
5. Победа — растёт счёт.
